# 数据分类、处理与留存基线

状态：第一阶段默认策略。法律/合同要求更严格时取更严格者；放宽必须通过安全评审和 ADR。

> 本文描述生产目标，不表示本地 V1 已完成全部控制。当前 SQLite 静态加密、自动删除、正式会话认证等差距见根目录 [`SECURITY.md`](../../SECURITY.md)；本地验证只应使用合成数据。

## 分类

| 等级 | 示例 | 中心端 | 最低控制 |
| --- | --- | --- | --- |
| C0 公开 | 用户主动发布的 Community Agent Card 公共字段 | 允许 | 明确发布/撤销；防爬取限流；不得默认跨 Community |
| C1 内部运营 | 聚合指标、无正文健康状态、非敏感配置 | 允许 | 员工最小权限；日志不带用户文本 |
| C2 受限个人数据 | Owner/Endpoint 标识、Intent Capsule、会话元数据、授权收据、举报 | 按用途允许 | 传输/静态加密；租户隔离；访问审计；禁止日志正文 |
| C3 临时机密内容 | Agent 间正文、被披露 Claim、Prompt/响应、附件摘要 | 仅为当前会话临时允许 | 独立加密与分区；目的限制；默认 Operator 不可见；到期删除 |
| C4 来源专属/密钥 | 原始文件、完整 Memory、Embedding、未披露 Claim、本地私钥/API Key | Memory 类禁止进入 Handshake；服务密钥仅进 Secret Manager | 不进应用数据库、日志、Trace、浏览器存储或工单；密钥可轮换 |

数据字段设计前必须标注：分类、所有者、目的、合法读取角色、存储位置、删除触发器和最大留存。没有标注的字段按 C3 处理，评审完成前不得上线。

## 默认留存

| 数据集 | 主存储最大留存 | 删除触发与验证 |
| --- | --- | --- |
| Agent Card / Intent Capsule | 有效期内；撤销或账户删除后 30 天 | 24 小时内下线不可发现；30 天内删除主存储并产出作业计数 |
| 消息正文、Prompt/响应、临时 Claim | `created_at + 7 天`；重试不得续期 | 每小时删除过期分区/行；告警最老过期记录年龄；正文不进入分析仓库 |
| Handshake 状态、transition、Envelope 元数据 | 暂定上限为会话终止后 365 天；试点前须经法律/合同评审批准 | 到期删除或不可逆匿名化；保留聚合指标不得可回溯个人 |
| 授权、撤销、双重同意收据 | 暂定上限为会话终止后 365 天；试点前须经法律/合同评审批准 | 删除主体标识与范围明细；仅保留不可回溯的聚合计数 |
| 举报、申诉、安全处置 | 暂定上限为案件关闭后 365 天；试点前须经法律/合同评审批准 | 法律保全需记录批准人、范围和到期时间 |
| 安全/Operator 访问审计 | 暂定上限 365 天；试点前须经法律/合同评审批准 | 仅安全角色可查；日志本身禁止含 C3/C4 内容 |
| Redis nonce/idempotency/在线状态/限流键 | 协议 TTL，最长 24 小时 | Redis TTL 强制设置；无 TTL 写入测试失败 |
| 去标识运行指标 | 90 天明细，之后只保留聚合 | 指标标签不得使用 Owner、Endpoint、Intent 或会话 ID |
| 原 AI / 本地 Agent Memory | 由来源 Agent 或供应商账号控制 | Handshake 不保留副本；本地 Agent 提供可验证删除，供应商数据按其账号能力管理 |

数据库备份保留不超过 30 天并加密、隔离访问。主存储完成删除后，不从日常备份恢复已删除数据；灾难恢复若使其重新出现，恢复流程必须在开放流量前重放删除墓碑。C3 表应尽量从长期逻辑备份排除；无法排除的加密备份只用于整库灾难恢复并随 30 天窗口自然失效。

## 处理规则

- 收集最少字段；不得以“以后可能有用”为目的收集。
- C2/C3 查询必须包含 `community_id` 和授权主体；数据库行级策略是应用校验之外的第二层保护。
- C3 采用与常规元数据不同的加密密钥；密钥轮换不要求重新暴露明文给业务日志。
- 日志只记录稳定错误码、Trace ID、截断/散列的技术标识和大小/耗时；异常对象发送前必须脱敏。
- 测试、开发、演示和模型评估只用合成或不可逆去标识数据；生产数据不得复制到本地开发环境。
- 第三方模型/通知供应商只接收当前用途所需最少内容；禁用训练，配置供应商最短留存，并在供应商清单中记录区域与删除能力。
- 导出数据需要重新认证、限速、一次性下载链接和完整审计；导出包不得包含其他 Community 或对端未授权内容。

## 删除与例外

用户删除请求到达后，24 小时内撤销发现、令牌和主动处理；按上表完成主存储删除，备份最迟 30 天失效。删除作业失败超过 24 小时或发现 C4 Memory 进入中心端时，按安全事件处理：停止相关写入、保全最小证据、通知安全负责人并执行对应 Runbook。

法律保全、欺诈调查等例外必须记录数据集、原因、批准人、开始/到期时间和复核日期。例外到期自动恢复删除，不允许无期限布尔标记。
